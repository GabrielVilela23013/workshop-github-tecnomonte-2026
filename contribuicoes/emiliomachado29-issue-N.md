Antes de fazer um commit, você precisa escolher quais arquivos quer incluir

usando git add. Depois, cria o commit:git commit -m "Mensagem explicando a mudança"

A opção -m permite escrever uma mensagem curta e clara, como:

"Corrige bug no cálculo de desconto"
"Adiciona página de login"
"Atualiza documentação"
