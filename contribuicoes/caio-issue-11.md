## O que é?
A git branch permite criar diferentes "fluxos" de trabalho que coexistem de forma paralela e individual, permitindo várias abordagens extremamente eficientes em desenvolvimento de Software.

## Como utilizar?
Criar uma branch para testar features novas e que ainda são nebulosas e incertas.

## Dica para iniciantes
Sempre tenha uma branch main, uma de desenvolvimento e uma para atualizações repentinas.
