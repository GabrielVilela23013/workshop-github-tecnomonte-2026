# git status

**Autor:** @cadusf

## O que é?
O git pull baixa as atualizações de um repositório remoto (como o GitHub) e as junta ao seu código local (equivalente a git fetch + git merge).

## Como utilizar?
rode "git pull"

## Dica para iniciantes
Rode git status antes de puxar as atualizações para garantir que seu código não tem alterações pendentes, evitando conflitos desnecessários.
