# Comando git status

**Autor:** @RishCoffe

## O que é?

O comando git status é utilizado para verificar
o estado atual dos arquivos de um repositório Git.

Ele permite identificar arquivos modificados,
adicionados ou que ainda não estão sendo
rastreados pelo Git.

## Como utilizar?

Abra o terminal dentro da pasta do projeto
e execute:

```bash
git status
```

O Git mostrará quais arquivos foram modificados
e quais alterações estão prontas para commit.

## Exemplo prático

Imagine que você modificou o arquivo README.md.

Ao executar git status, o Git informará que
esse arquivo foi alterado.

Assim, você poderá verificar as mudanças
antes de registrar um commit.

## Dica para iniciantes

Sempre execute git status antes de fazer
um commit. Isso ajuda a identificar quais
arquivos foram modificados e evita
adicionar alterações indesejadas.
