# git commit -m --amend "<message>"

**Autor: yuryzada**

## oque é?
Muda o nome do ultimo commit que ainda nao foi para a origem

## Como ultilizar
mensagem do commit antigo:
"feat: implementacao do logn"

comando:
```
-git commit -m --amend "feat: implementacao do login"
```

resultado da nova mensagem:

"feat: implementacao do login"
