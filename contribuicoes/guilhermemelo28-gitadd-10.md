## GIT ADD

User:guilhermemelo28 


Como funciona o git add? R: O comando git add serve para preparar os arquivos que você modificou para o próximo commit.Ele coloca os arquivos na chamada Staging Area (área de preparação).

Exemplo:
pasta/
-----index.html
    No terminal, apos configurar a pasta no GitHub:
        git add index.html


Dicara para iniciantes: Evite usar git add . , pois esse comando  adiciona todas as alterações da pasta atual e subpastas, inclusive arquivos que você não queria colocar no commit.
