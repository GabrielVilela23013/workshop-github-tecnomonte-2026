# git init
**Autor:** @heitor-castro

## O que é?
O comando git init é o ponto de partida absoluto para o controle de versão em um projeto utilizando o Git. A sua função primordial é inicializar um repositório Git novo e vazio (ou reinicializar um já existente) dentro de um diretório específico do seu sistema de arquivos.

## Como utilizar?
Na pasta que irá para o repositório, use na linha de comando "git init".

## Dica para iniciantes
Na pasta, clique com o botão direito do mouse, logo, escolha o opção "Abrir no terminal", dessa forma, a pasta será rapidamente aberta no terminal.
