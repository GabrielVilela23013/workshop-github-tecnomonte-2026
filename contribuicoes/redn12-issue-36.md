# git status

**Autor:** @RedN12

## O que é?

O comando `git status` permite verificar o estado atual do repositório Git. Com ele, podemos identificar arquivos modificados, arquivos novos e alterações que ainda não foram preparadas para um commit.

É um comando muito útil para acompanhar o que mudou no projeto antes de registrar as alterações.

## Como utilizar?

No terminal, dentro da pasta do repositório, execute:

```bash
git status
```

O Git mostrará informações sobre a branch atual e sobre os arquivos que possuem alterações.

Por exemplo, se você criar um arquivo novo ou modificar um arquivo existente, o comando `git status` poderá indicar essas mudanças.

## Dica para iniciantes

Execute `git status` frequentemente durante o trabalho. Assim, você consegue conferir quais arquivos foram modificados antes de realizar um commit e evita registrar alterações por engano.
